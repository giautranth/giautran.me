2. YÊU CẦU MÁY CHỦ HỆ THỐNG (SYSTEM REQUIREMENTS)
--------------------------------------------------------------------------------
Nếu cần chuyển sang nhà cung cấp máy chủ / hosting khác trong tương lai:
- Hệ điều hành: Linux (Ubuntu / Debian / CentOS / CloudLinux)
- Máy chủ web: Apache 2.4+ (có bật mod_rewrite) hoặc Nginx
- Phiên bản PHP: PHP 8.0 trở lên (khuyên dùng PHP 8.1 hoặc 8.2)
- Cơ sở dữ liệu: MySQL 5.7+ hoặc MariaDB 10.3+
- Nền tảng CMS: WordPress phiên bản 6.0 trở lên

--------------------------------------------------------------------------------
3. HƯỚNG DẪN KHÔI PHỤC WEBSITE (DISASTER RECOVERY / MIGRATION)
--------------------------------------------------------------------------------
Bước 1: Cài đặt một bản WordPress sạch trên hosting mới.
Bước 2: Tạo một cơ sở dữ liệu mới và import file 'vegangarden_database_backup_20260925.sql'.
Bước 3: Copy thư mục 'vegangarden_wp_theme' vào thư mục 'wp-content/themes/' trên máy chủ.
Bước 4: Đăng nhập vào trang quản trị WordPress -> Giao diện (Appearance) -> Kích hoạt theme 'Vegan Garden'.
Bước 5: Cấu hình lại file 'wp-config.php' khớp với tên database và mật khẩu mới.

Website sẽ hoạt động lại 100% nguyên vẹn như phiên bản đang chạy online.
